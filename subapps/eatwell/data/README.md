# EatWell reference food data

`fooddb.json` holds 6,494 foods with nutrients per 100 g, generated by `../scripts/build-fooddb.py` from the
[TempoLife food dataset](https://tempolife.app) (npm `tempo-food-db@1.0.0`), which is mostly USDA FoodData Central SR Legacy.

- **Attribution (CC-BY-4.0):** "Food nutrition data from TempoLife (tempolife.app), CC-BY-4.0." Shown in the app (Foods tab).
- USDA FoodData Central data is in the public domain.
- Only the data is used; the package's code is never run or bundled. Values are reference values per 100 g; the owner logs by weight.
